# Uso de IA — Front-end

Ferramenta utilizada: Codex (OpenAI).

O autor desenvolveu a estrutura inicial em React e TypeScript, o formulário,
o controle dos campos e o fluxo de chamada HTTP à API por meio do handleSubmit.

A IA foi utilizada para aprimorar a apresentação visual com Tailwind CSS,
ajustar detalhes de layout e criar a paginação da listagem de professores.
As sugestões foram revisadas e adaptadas pelo autor.

## Erro identificado e ajuste

A primeira proposta visual utilizava arquivos CSS separados, enquanto a abordagem
adotada para o projeto era Tailwind CSS. A divergência foi identificada na revisão
da proposta e corrigida com classes utilitárias nos componentes.
